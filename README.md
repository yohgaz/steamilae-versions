# Steamilaé — versions

Installateurs Windows de **Steamilaé**, un launcher moderne pour tes jeux Steam.

- Pour l'installer : ouvre l'onglet **Releases** et télécharge le fichier `.exe` de la dernière version.
- Une fois installé, Steamilaé se met à jour tout seul : il consulte `latest.json` ici au démarrage et te propose la nouvelle version (l'installateur est signé, Steamilaé vérifie la signature avant de l'installer).

Le code de l'application vit dans un dépôt privé ; ce dépôt-ci ne contient que les versions publiées.
